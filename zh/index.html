开始前的几个问题。

BioPaster 是什么？

BioPaster 是面向生物医学研究的开源命令行 AI Agent，将语言模型与文献、本地文件、代码执行和 Jupyter Notebook 连接起来。项目以 Python 编写，源码发布在 GitHub。

能用本地小参数模型运行吗？

可以。项目已使用本地 9B 模型测试流式输出、工具调用和会话标题生成。需要选择支持工具调用的模型，以及兼容 Anthropic Messages API 的服务。任务完成质量取决于模型能力和问题本身。

本地推理意味着完全离线吗？

模型可以在自己的电脑运行，无需云推理服务。但文献搜索、文件下载和外部 MCP 服务仍可能访问网络，取决于启用和调用的工具。

分析完成后可以检查什么？

可以检查 Notebook 中保留的代码与输出、来源证据文件和历史会话。复现还需要原始输入数据及兼容的软件环境，仅有 Notebook 不代表一定能够复现。
